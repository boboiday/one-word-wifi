# One Word for Your Wi-Fi

Entry for the make.fun bounty [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72).

The program writes one word — **Wi-Fickle** (9 characters) — to `/output/entry.txt`: the funniest and most accurate description of home Wi-Fi. Full bars in the living room, dead in the bedroom, drops mid-call. Fickle is exactly what it is.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
